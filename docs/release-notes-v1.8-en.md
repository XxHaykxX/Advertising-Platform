Release v1.8 — July 24, 2026

What's new and what's fixed on igovazd.am.

— Projects —
1. Video on the project page. Add a video via a YouTube/Vimeo link or a direct MP4 upload.
2. Description in three languages. The full description and the short logline are filled in Armenian, Russian and English on separate tabs.
3. Drag-and-drop ordering. The display order of projects is arranged by dragging with the mouse.
4. Gallery reordering. Project images are also rearranged by dragging.
5. Genre moved after "Type". The field order is now more logical.
6. The "Code" field is hidden everywhere, including the edit form.
7. Synopsis removed from catalog cards for a cleaner look.

— Cast / crew —
8. Global cast & crew directory. Add, edit and delete people in one place and reuse them across projects.
9. A new member is added at the top, with the cursor auto-focused on the name field.
10. The cast list is reordered by dragging.

— Images & media —
11. All images now use a unified 16:9 ratio.
12. Upload many files at once by dragging them into the media library.
13. A download button on each file in the library.
14. Picking an image opens the server library, not just your computer's files.

— Edit form —
15. Two-column form: content on the left, settings on the right.
16. Compact tables for cast and sponsorship tiers.
17. A sticky "Save" bar at the top of the page.
18. After "Save" you stay on the same page with a green "Saved" confirmation.
19. Unsaved changes are now marked in red.
20. The "Cancel" button moved next to "Save".
21. Hand (pointer) cursor on all buttons and links.

— Admin panel —
22. Grouped navigation: Content / Platform / Communications.
23. Collapsible sidebar whose state is remembered for your next visit.
24. Search by name in the projects list, plus colored status badges.
25. Wider working area.

— Fixes —
26. Sponsorship tier benefits show in full and are no longer cut off.
27. "Translate" no longer wipes fields you already filled in.
28. Fixed several display and stability issues.
29. Internal security and performance improvements.
