Все три тикета от Mariam Petrosyan, все переведены в UAT с комментариями и @Hrach Tashchyan.

**IA-40** — страница проекта печатала один жанр: `report-hero.tsx` передавал в key-facts

**IA-41** — карточка: бейдж жанра поверх постера убран (а ряд под названием начинался со
второго жанра — теперь с первого, до трёх + «+N»); строки формата и гео рендерятся только
при значении; над площадками появилась подпись `card.availableOn`.

**IA-42** — дата релиза больше не блокирует публикацию; добавлена точность даты
(DAY/MONTH/YEAR) с хранением в плейсхолдер-дату (`YYYY-01-01` / `YYYY-MM-01`) и выводом
строго по точности; дедлайн получил флаг «Ongoing» — вместо даты и обратного отсчёта
печатается «Ընթացիկ», проект не считается просроченным и не выпадает из каталога.
`isArchived()` принимает флаг, появился `compareDeadline()` (даты → ongoing → без дедлайна).

### Что нашло ревью (все пять починены до выката)

1. 🔴 **Откат версии создавал невозможную строку.** `restoreToVersion`/`restoreDeletedRecord`
   пишут только поля из снапшота: старый снапшот возвращал дату дедлайна, а флаг
   `applicationDeadlineOngoing=true` на строке оставался → «Ongoing» поверх даты, и проект
   вечно жил в каталоге, потому что `isArchived()` замыкается на флаге. Лечение —
   `normalizeProjectRestore()`: дефолты для отсутствующих колонок + правило «ongoing ⇒ дата
   null». **Правило: любая новая колонка-модификатор требует нормализации в restore.**
2. 🔴 **`<input type="month">` не реализован в десктопных Firefox/Safari** — вырождается в
   текстовое поле, так что серверу прилетает «Май 2027»: сохранялось NULL при точности MONTH
   (форма рапортует успех, дата исчезает) либо парсилось по локальному времени и уезжало на
   месяц назад. Лечение — серверная проверка формы значения под выбранную точность.
3. 🔴 **Размонтированный `<input>` возвращается со `defaultValue`.** Поле дедлайна прячется
   по чекбоксу; ввёл дату → включил Ongoing → выключил ⇒ сохранялась старая дата. Поля,
   которые прячутся, держать в state (`CONTROLLED_NAMES` + restoreDraft).
4. Пустой серый чип жанра, когда нет ни `genres`, ни легаси `genre` (`[""]`).
5. Год без серверной проверки диапазона: «20277» переполнял MySQL DATETIME → 500 вместо
   ошибки поля.

Ревью также подтвердило: SQL миграции соответствует схеме на MariaDB, порядок «сначала SQL,
потом push» безопасен (старый Prisma-клиент перечисляет колонки явно), публикационный гейт
консистентен после снятия требования даты.
