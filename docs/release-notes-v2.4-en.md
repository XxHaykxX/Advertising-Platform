Release v2.4 — July 31, 2026

What's new and what's fixed on igovazd.am since v2.3.

— The project page —
1. The four facts about a project — genre, format, studio, countries — now sit inside the offer card on the right, each with a label saying what it is. They used to sit under the image as bare values next to small icons, so a studio name appeared as a word with nothing explaining it, and the space beside the offer card sat empty.
2. The production stage badge ("Filming", "Pre-Production") no longer covers the corner of the poster. It told a brand nothing it could act on and hid part of the image; the stage is still shown on the production timeline, where it has context.
3. The details block is reorganised around the order a brand decides in: where the project will be seen, when it comes out and when offers close, and what it is comparable to. Each group is now a panel with its own heading rather than one long list, comparable titles get a wider row of posters, and the empty half of the block is gone — the space had been reserved for a button that is not shown to everyone.
4. Dragging the cast, timeline and storyboard strips with the mouse is smooth. The strip used to be pulled backwards as you dragged, fighting the cursor, and stopped dead the moment the button was released; it now follows the cursor exactly and glides to a stop like a swipe on a phone.

— Profiles —
5. The website field now shows the address that was actually saved. Typing an address with the wrong slashes was quietly corrected before storing, but the field kept showing the original text, so there was no way to tell that anything had been checked.
6. The creator profile checks the website address the same way the brand profile does. It used to save whatever was typed, with no check at all.
7. Saving the brand profile no longer flickers. For a fraction of a second after pressing Save, the budget range showed the previously saved option before snapping back to the correct one.

— Elsewhere —
8. Translations continue to be filled in across the site. Project descriptions that still appear in Armenian on the Russian and English versions are being completed by the content team; the pages themselves show whichever language exists and fall back to the original.
9. The case studies section is hidden until there are real cases to show. The six entries on it were demonstration material — invented brands and numbers — under a heading promising real results. Nothing was deleted; the section returns as soon as genuine case studies are ready.
