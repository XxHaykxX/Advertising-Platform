## 2. Форма проекта — задеплоено (prod `4072975`)

- **Починен регресс:** чеклист «что видит бренд» показывал сырые ключи
  (`completeness.item.tagline`). Причина — сборщик клиентских ключей вёл список

  подсвечивается ~2.2 с (`src/lib/field-flash.ts`, `.field-flash` в `globals.css`).

  повторяли подпись (название проекта, имя в касте, название и ссылка референса).
  В списке возрастного рейтинга вместо прочерка — «Не указан».
