## Ресёрч (3 агента параллельно: UX, маркетинг, инвентарь страницы)

- **NN/g (icon usability):** иконка без подписи узнаётся через раз. «Kinodaran» рядом с иконкой
  здания — просто слово без объяснения. Подпись должна быть видимой всегда, не по ховеру.
- **Baymard (spec sheet scannability / post-processing):** характеристики нужно группировать под
  заголовками, иначе «стена спеков»; непоследовательные подписи для одного и того же атрибута
  читаются так же плохо, как отсутствие атрибута. Один товар — одна колонка, многоколоночный
  спек-лист читается как таблица сравнения.
- **B2B PDP / progressive disclosure:** сначала контекст и доверие, потом призыв к действию;
  медиакит устроен «кто вы → аудитория → доказательства → цена», то есть нарратив перед цифрами.
- **Маркетинг (product placement):** решение бренда определяют, по убыванию: аудитория/охват →
  brand safety и попадание в тон → как именно продукт появится в кадре → гарантии (сцены/минуты)
  → эксклюзив по категории → площадки и окно релиза → цена. **Аудитории/охвата на странице нет
  вообще** — это самый дорогой пробел, дороже любой вёрстки. Статус производства для бренда
  значим только как «до съёмок ещё можно вписаться в сценарий», плашкой на постере он бесполезен.

## Грабли и уроки

1. **«Правки не видны» — сервер на 3001 был `next start`, а не `next dev`.** Прод-сборка из
   старого `.next`, HMR не при чём. Проверять командную строку процесса
   (`Get-CimInstance Win32_Process`), прежде чем искать кэш браузера.
2. **Свайп «не плавный» = CSS scroll-snap против прямых записей `scrollLeft`.** `scroll-behavior`
   уже нейтрализовали 29.07 — это была не та половина проблемы. Пока идёт drag, браузер
   пересчитывает точки привязки на каждую запись и тянет ленту назад. Снап снимается на время
   перетаскивания и возвращается **только после того, как затухнет инерция** (вернуть на pointerup
   — снап будет драться с флингом).
3. **Пустая половина карточки — это зарезервированная колонка под кнопку.** `lg:grid-cols-[1fr_auto]`
   держит колонку, даже когда внутри `null` (creator/staff кнопки не видят). Считать CTA заранее
   и рендерить строку вместе с ним.
4. **Правку агенту нужно слать до того, как он закончит.** «Иконки оставить» пришло, когда агент
   уже вырезал `icon` prop; пришлось возвращать вторым проходом.
5. Ошибка `Cannot read properties of undefined (reading 'genre')` в консоли dev — след HMR между
   правками (старый hero + новая карточка), а не живой баг: после перезагрузки консоль чистая,
   `tsc` чист, `DealCard` вызывается ровно из одного места.
