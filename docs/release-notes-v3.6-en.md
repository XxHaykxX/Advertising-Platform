Release v3.6 — August 21, 2026

What's new and what's fixed on igovazd.am since v3.5.

— Submitting a project —
1. Typing in "Short description" no longer breaks the page. After the second word the form was replaced by an error screen and everything filled in up to that point was lost — which is why the character counter appeared to be stuck as well.
2. The video link is now checked before it is saved. Any text at all used to be accepted, so a project could end up published with a link that leads nowhere; a plain address like `youtube.com/watch?v=…` still works and gets completed to a full one for you.
3. When a link is refused, what you typed stays in the field next to the explanation instead of disappearing.

— Listing an ad space —
4. Pressing "Submit for review" from the bar at the top now takes you to the reason it was refused. The message sat at the very bottom of a form several screens long and was easy to read as nothing having happened at all.
5. That message is now red with a warning icon, so it is no longer mistaken for a notice. The red dot marked "Unsaved changes" beside the button is a status, not an error.

— Languages —
6. Switching the language now changes the whole site at once. Pages you had already opened kept the previous one, so a page could show its menu in one language and its heading, its buttons and its Channel and City lists in another.
7. The error screen shown when something goes badly wrong now speaks the language of the site. It was always in Russian, including for anyone reading in Armenian or English.

— Elsewhere —
8. The heart for saving a project is no longer shown to accounts that cannot use it. Saving to a shortlist is something a brand does, so for a creator it was a button that never responded.
